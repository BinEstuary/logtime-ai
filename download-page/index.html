Hướng dẫn cài đặt

App chưa được ký số nên hệ điều hành có thể cảnh báo khi mở lần đầu.

Windows
  1. Chạy file .exe vừa tải.
  2. Nếu hiện cảnh báo SmartScreen: bấm More info → Run anyway.
  3. Làm theo trình cài đặt.
macOS
  1. Chọn bản Apple Silicon cho máy M1/M2/M3/M4, bản Intel cho máy đời cũ.
  2. Mở file .dmg, kéo LogTime AI vào thư mục Applications.
  3. Lần đầu mở: chuột phải vào app → Open → Open.
  4. Nếu báo app "bị hỏng": chạy xattr -cr "/Applications/LogTime AI.app" trong Terminal.
Linux
  1. AppImage: chmod +x LogTime-AI-*.AppImage rồi chạy file.
  2. Ubuntu/Debian: sudo apt install ./LogTime-AI-*.deb
